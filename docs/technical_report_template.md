# Smart POS with E-Invoicing — Technical Report (Template)

## 1. Introduction
Brief overview, objectives, and scope.

## 2. Architecture
- Flutter mobile app (Android/iOS)
- FastAPI backend
- SQLite for development
- Postman Mock server for e-invoicing

## 3. API-First Design
OpenAPI auto-generated by FastAPI (`/docs` & `/openapi.json`).

## 4. Key Modules
- Products (CRUD)
- Sales (compute totals, tax, discount)
- Invoices (build JSON, submit to mock, log response)
- Reports (daily sales, tax summary)

## 5. Offline Strategy
Local queue using shared_preferences; retries on connectivity.

## 6. Security
Token stub; could be upgraded to JWT.

## 7. Testing
Postman collection included; manual tests for core flows.

## 8. Deployment
Run FastAPI with Uvicorn; configure env vars.

## 9. Limitations & Future Work
- Rich receipts (PDF/print), robust auth, better offline storage (SQLite), unit tests.
