# Smart POS Backend (FastAPI)

## Quickstart
```bash
python -m venv .venv && source .venv/bin/activate  # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
Open Swagger UI at http://127.0.0.1:8000/docs

## Env
Copy `.env.example` to `.env` and adjust values.

## Seed
To seed SQLite:
```bash
sqlite3 pos.db < app/seed.sql
```

## Endpoints
- `GET /products` CRUD for products
- `POST /sales` create sale (computes totals/tax/discount)
- `POST /invoices/submit` send to mock tax service and log response
- `GET /reports/daily-sales`, `GET /reports/tax-summary`

## Notes
- OpenAPI is auto-generated by FastAPI.
- Replace `MOCK_EINVOICE_URL` with your Postman Mock URL.
